# 日历 · Just be present.

简约日历网页应用，浅灰底、细线网格、带农历。打开即用，不用注册，不用登录。

## 隐私

- 所有事项只保存在**你自己的浏览器**（localStorage）里，不会上传到任何服务器。
- 每个人打开都是自己的日历，别人看不到你的事项。
- 换浏览器、换设备、清空浏览器数据后，事项不会跟着走——可以用页面里的「导出备份」存一份 JSON，需要时再「导入备份」恢复。

## 功能

- 月历 / 日程两种视图，网页端左侧导航栏、手机端底部导航
- 月历格子里显示农历日期与传统节日，今天用灰蓝圆圈标记
- 点任意一天查看详情，添加、修改、删除事项（全天或具体时间、备注）
- 侧边栏有实时模拟时钟和「接下来的安排」
- 导出 / 导入 JSON 备份

## 技术

纯静态页面（HTML + CSS + JS），无后端。农历换算使用 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT 协议，已随仓库附带 `lunar.js`）。
